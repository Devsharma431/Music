# XO // AFTER HOURS — The Weeknd World

A polished, responsive, fan-made single-page music experience.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

## Music / copyright
The project uses YouTube embeds and links rather than bundling copyrighted audio files. Replace/add video IDs only for videos you are authorized to embed or otherwise use.

## Files
- index.html — page structure
- styles.css — visual system / responsive design
- app.js — track data + player interactions
